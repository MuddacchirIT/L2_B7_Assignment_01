Effective pillars of OOP---

Inheritance : Inheritance is an Object-Oriented Programming (OOP) concept where one class acquires the properties and methods of another class. The role of inheritance in programming is to allow one class to reuse the properties and methods of another class. It helps create a relationship between classes and reduces code duplication.

Polymorphism : Polymorphism is used because it makes code flexible, reusable, and easier to maintain by allowing one interface (method or function) to work with different types of objects in different ways.

Abstraction : Abstraction is an Object-Oriented Programming (OOP) concept that focuses on hiding implementation details and showing only the essential features of an object. Abstraction is used to hide complex implementation details and show only the necessary features of an object.

Encapsulation : Encapsulation is an Object-Oriented Programming (OOP) concept where data (variables) and methods (functions) are wrapped together inside a class, and access to that data is controlled. Encapsulation is used because it helps protect data, control how it is accessed, and make code safer and easier to maintain.
